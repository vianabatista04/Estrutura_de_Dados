# Estrutura de Dados com JavaScript e TypeScript 🟨🟦

Repositório destinado ao armazenamento e organização das atividades práticas desenvolvidas na disciplina de **Estrutura de Dados**, ministrada pelo professor **Guilherme Leal** no curso de **TADS - IFRN**.

---

## 📌 Sobre a Disciplina

A disciplina abrange desde os fundamentos de lógica e estruturas nativas em JavaScript até a transição para TypeScript e a implementação de estrutura de dados lineares e não-lineares avançadas, finalizando com testes unitários e boas práticas de código.

### Conceitos Explorados:

* **Fundamentos JS & ES6+:** Métodos funcionais de array (`map`, `filter`, `reduce`), manipulação de objetos e coleções (`Map`, `Set`).
* **Estruturas Lineares:** Implementação manual de Pilhas (*Stacks*), Filas (*Queues*) e Listas Encadeadas (*LinkedLists*).
* **Fundamentos de TypeScript:** Tipagem estática, *Interfaces*, *Type Aliases* e Programação Orientada a Objetos (POO).
*  **Generics e Tipos Avançados:** Criação de estruturas genéricas e redefiníveis (`<T>`).
*  **Estruturas Avançadas:** Tabela Hash (*Hash Tables*), Árvores Binárias (*Binary Trees*) e Grafos (*Graphs*).
*  **Qualidade de Código:** Testes unitários com Vitest/Jest e aplicação de princípios de *Clean Code*.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagens:** JavaScript (ES6+) e TypeScript (v5.0+)
* **Ambiente de Execução:** Node.js (v18+)
* **Servidor Local:** Live Server (VS Code Extension)
* **Executador TS:** `tsx` (Fast TypeScript Execute ou Execução Direta em CLI)
* **Framework de Testes:** Vitest
* **IDE/Editor:** Visual Studio Code (VS Code)

## 🚀 Como Executar

### 🟨 JavaScript / 🟦 TypeScript

** 1. 💻 Instalar dependências:**
   ```bash
   npm install
   ```

### 2. 🌐 Execução no Navegador (JavaScript via Live Server)

1. Abra a pasta do projeto no **VS Code**.
2. Certifique-se de ter a extensão **Live Server** instalada.
3. Abra qualquer arquivo `.html` (ex: `index.html`) associado ao script JavaScript desejado.
4. Clique com o botão direito no arquivo HTML e selecione **Open with Live Server** (ou aperte `Alt + L, Alt + O`).
5. No navegador, abra o **Console do Desenvolvedor** (`F12` ou `Ctrl + Shift + I`) para visualizar as saídas e manipular as estruturas.

> ⚠️ Usado somente para JavaScript, caso queira usar o TypeScript necessita compilar o código em JavaScript.
