# Cadastro Acadêmico Modular

Aplicação didática em JavaScript para cadastro de alunos em memória.
O projeto demonstra funções, callbacks e módulos ECMAScript.

## Requisitos

- Node.js instalado
- npm

## Instalação

bash
npm install

## Execução

bash
npm start

## Funcionalidades

- Cadastrar aluno
- Validar dados
- Calcular média e situação
- Listar alunos
- Remover aluno por matrícula

## Organização

- `models`: criação das entidades
- `repositories`: armazenamento em memória
- `services`: coordenação dos casos de uso
- `utils`: cálculos e validações
- `ui`: apresentação no console

## Limitações

- Os dados são perdidos quando o programa termina.
- A validação de e-mail é apenas introdutória.
